# RESONANT

> *An orbital descent — a twitch-reflex flow-state game for Android.*

A glowing particle orbits a central nexus. Concentric rings of geometric obstacles surround
it, each rotating at a different speed and direction. You don't steer the particle — you
choose its **orbital radius**, switching rings inward or outward as you predict where the
gaps will be. Survive the rotation. Find the flow.

Inspired by the design DNA of *Race the Sun* and *Super Hexagon* — minimalist geometry,
music-driven rhythm, instant retry, escalating speed — but built on a novel mechanic:
**radial lane-switching against contrasting ring rotations**.

---

## Game Design

| Pillar | Detail |
|--------|--------|
| Core mechanic | Tap left → ring inward; tap right → ring outward |
| Player input | One axis. No steering, no aiming, no menus |
| Death | Instant. Your particle hits a solid ring segment → death VFX → retry screen |
| Retry | Tap once. The next attempt starts in <1 second |
| Score | Time × speed multiplier; high score persisted |
| Sessions | 30 sec (novice) → 3 min (expert) |
| Music | Real-time procedural electronic track — bass + pad + arpeggio + drums @ 128 BPM |

### Difficulty Curve

| Time (s) | Active Rings | Speed Mult | Obstacle Density |
|----------|--------------|------------|-----------------|
| 0–30     | 3            | 1.0× → 2.2× | 4/8 segments |
| 30–60    | 4            | 2.2× → 3.4× | 4/8 → 5/8     |
| 60–90    | 5            | 3.4× → 4.0× | 5/8 → 6/8     |
| 90+      | 5            | 4.0× (cap)  | 6/8           |

## Building the APK

### Requirements

- **JDK 17** (Android Gradle Plugin 8.1 does not support JDK 21)
- **Android SDK** with platform 34 + build-tools 34.0.0
- The bundled `gradlew` Gradle wrapper handles the rest

### One-time setup

Create a `local.properties` file at the project root pointing to your Android SDK:

```properties
sdk.dir=/path/to/your/android/sdk
```

Or set the `ANDROID_HOME` environment variable:

```bash
export ANDROID_HOME=/path/to/your/android/sdk
export JAVA_HOME=/path/to/jdk-17
```

### Build the debug APK

```bash
./gradlew :android:assembleDebug
```

Output: `android/build/outputs/apk/debug/android-debug.apk`

### Install on a connected device

```bash
adb install -r android/build/outputs/apk/debug/android-debug.apk
adb shell am start -n com.resonant.game/.AndroidLauncher
```

## Architecture

LibGDX 1.12.1, Java 11, multi-module Gradle project.

```
core/   — Platform-agnostic game logic (no Android dependencies)
android/ — Android launcher + manifest + native lib extraction
```

### Key files

| File | Role |
|------|------|
| `core/src/com/resonant/game/GameConfig.java` | All tunable constants |
| `core/src/com/resonant/game/model/GameWorld.java` | Simulation, collision, scoring |
| `core/src/com/resonant/game/model/Ring.java` | Ring state + O(1) collision query |
| `core/src/com/resonant/game/util/RingSegmentDrawer.java` | Annular sector tessellation |
| `core/src/com/resonant/game/audio/MusicSequencer.java` | Procedural music synthesis |
| `core/src/com/resonant/game/audio/AudioEngine.java` | Real-time PCM thread |
| `android/AndroidManifest.xml` | Landscape, GLES2, immersive |
| `android/build.gradle` | Native library extraction task (CRITICAL) |

### Rendering

All visuals are procedural geometry via `ShapeRenderer`. No texture atlases, no PNG assets.
Pseudo-bloom glow is achieved by stacking alpha-decreasing layers under additive blending.

### Audio

A daemon thread fills LibGDX's `AudioDevice` with 44.1 kHz mono PCM samples generated by
`MusicSequencer`. The composition (Am → F → C → G in 4-beat measures) is fully deterministic —
no audio asset files required.

### Performance budget

- 5 rings × 8 segments × 18 tessellation steps × 2 triangles = 1,440 triangles per frame
- Stable 60 fps target on minSdk 24 devices

## Controls

- **Tap left half** of screen → orbital radius decreases (move toward nexus)
- **Tap right half** of screen → orbital radius increases (move toward edge)
- 100 ms cooldown between switches (prevents accidental double-tap)
- Keyboard (desktop): A/Left/Down = inward; D/Right/Up = outward

## Why this game

*Race the Sun* and *Super Hexagon* both rely on a single elegant mechanic, escalating
difficulty, and a music-driven flow state. RESONANT borrows that DNA but introduces a
genuinely novel idea: **the player never controls direction**, only depth. The world rotates
around you in opposing layers, and mastery emerges from learning to *predict* rotation rather
than *react* to obstacles.

This isn't an endless runner. It's not a hexagon. It's an orbital descent.
